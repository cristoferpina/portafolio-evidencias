## Ejecutar las prácticas

Con Python 3 instalado:

```bash
git clone https://github.com/cristoferpina/portafolio-evidencias.git
cd portafolio-evidencias
python -m http.server 8000
```

Abre [localhost:8000](http://localhost:8000) y selecciona una carpeta. También puedes abrir el HTML de cada práctica directamente en el navegador.

<a id="seccion-5"></a>

## Editar los proyectos

Cada práctica conserva sus recursos. Mantén las rutas relativas al modificar imágenes y estilos. Para SASS, edita los archivos SCSS y compila el CSS antes de revisar los cambios.
